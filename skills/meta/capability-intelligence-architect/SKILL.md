# Capability Intelligence Architect (CIA)

CIA treats skills as capabilities within an evolving architecture rather than isolated modules.
The framework identifies available skills, analyzes relationships, detects overlaps, discovers capability gaps, recommends workflows, and proposes future improvements.

---

## When to Use This Skill

Use CIA when:
- Auditing the installed skill ecosystem
- Identifying capability gaps before building new features
- Evaluating overlaps and redundancies
- Planning future skill development
- Visualizing capability maturity and readiness

---

## Core Functions

### Skill Discovery
Identify and catalog available skills.

### Capability Mapping
Organize skills into capability domains.

### Relationship Analysis
Map dependencies and complementarities.

### Overlap Detection
Detect redundant or highly similar skills.

### Gap Analysis
Identify missing capabilities.

### Workflow Generation
Recommend optimal skill sequences.

### Capability Maturity Assessment
Evaluate capability development levels.

### Redundancy Audit
Highlight unnecessary duplication.

### Skill Recommendation
Propose new skills with highest expected impact.

### Evolution Roadmap
Generate long-term capability development plans.

---

## Output Structure

### Available Capabilities
List discovered skills.

### Capability Domains
Group skills by function.

### Relationship Graph
Describe interactions between skills.

### Overlap Assessment

### Recommended Workflows
